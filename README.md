# Horizon World Map (Rust Edition)

<img src="https://raw.githubusercontent.com/kroniksdwdwd/Horizon-WorldMap/refs/heads/main/icon.png" width="256" alt="Icon">

A custom, high-performance client-side world map mod for the **Horizon** client, written in **Rust**. 
This project is based on the files of Xaero's World Map, adapted and optimized for the Rust ecosystem.

## 🎮 Default Controls
You can change all of these keybinds in the mod's settings menu within Horizon.

| Key | Action |
| :--- | :--- |
| **M** | Open / Close the map menu |
| **=** (Equals) | Zoom In |
| **-** (Minus) | Zoom Out |
| **Arrow Keys** | Pan / Move the map |
| **C** | Center map on the player |

## 🚀 Installation & Requirements
1. Ensure you have the **Horizon** client installed.
2. Download the latest `.hnmod` release in `\dist\horizonworldmap.hnmod`.
3. Place the file in your Horizon mods folder.
4. Launch the game and press **M** to open the map!

*Note: This is a native Rust mod. It does not require Java and will not work with standard Forge/Fabric loaders.*
